micromachee — a 240x160, eight-colour console that lives in your bar

PLAYING
  micromachee status          one line of JSON for the bar
  micromachee list            the shelf, as JSON
  micromachee covers          every cart's cover art, as JSON
  micromachee tty <id>        play it here, in this terminal
  micromachee play <id>       run a cart (frames on stdout, buttons on stdin)
  micromachee sync            fetch carts from the catalog
  micromachee catalog         write catalog.json from carts/ (for publishing)
  micromachee scale [2-6]     how big the screen is drawn
  micromachee doctor          where everything lives

MAKING A GAME
  micromachee new "<name>"    write a starting cart that already plays
  micromachee make "<name>" "<what it is>"   have Claude write one
  micromachee revise <id> "<change>"         change one it wrote
  micromachee publish <id>    move a draft onto the shelf
  micromachee submit <file|id>  send it to the PUBLIC shelf — verified
                              automatically (a sandboxed run + reviewers),
                              live for everyone within the minute if accepted
  micromachee discard <id>    throw a draft away
  micromachee check <file>    does it load, and survive a minute of play?
  micromachee cover <id|file> [-o out.png]   look at its cover
  micromachee shot <file> [--frames N] [--hold 2,4] [--keys 5:2,6:0]
                              [-o out.png]
                              look at it. --hold holds buttons down;
                              --keys is a frame:mask track, so a TAP is
                              expressible — which is the only way to drive a
                              game that reads btnp()

A cart is one Lua file, at most 24K, drawn on 240x160. It needs _draw();
_init() and _update() are optional. 30 frames a second.

  cls(c) pset(x,y,c) pget(x,y) rect(x,y,w,h,c) rectb(x,y,w,h,c)
  line(x0,y0,x1,y1,c) circ(x,y,r,c) circb(x,y,r,c) print(text,x,y,c,scale)
  btn(i) btnp(i) t() rnd(n) flr(n) mid(lo,v,hi) score(n)

Colours 0-7: black navy red orange yellow green blue white
Buttons 0-5: left right up down O(z) X(x)
